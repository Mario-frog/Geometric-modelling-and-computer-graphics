# Лабораторна робота №1 Варіант 15
## C++17 + Qt 6 Widgets

Реалізовано:
- побудову координатної сітки та осей;
- модель деталі варіанта 15;
- зміну розмірів деталі;
- евклідові перетворення: зсув і обертання навколо довільної точки;
- масштабування;
- симетрію відносно довільної точки;
- афінне перетворення;
- проективне перетворення;
- власний клас Matrix3 для матриць 3x3 (без QTransform для перетворення моделі).

## Математика
Точка - стовпчик (x,y,1)ᵀ, p' = M·p, композиція A·B = "спочатку B, потім A". Власний клас Matrix3.
- Зсув: T(dx,dy). Обертання навколо (px,py): T(p)·R·T(-p); додатний кут - за годинниковою стрілкою (як на зразку ТЗ).
- Масштаб: T(p)·S(sx,sy)·T(-p). Симетрія відносно точки: масштаб (-1,-1) відносно неї.
- Афінна система координат (X, Y - вектори осей, O - початок): x' = Xx·x + Yx·y + Ox, y' = Xy·x + Yy·y + Oy.
- Проективна (X, Y, O - точки з вагами wX, wY, w0):
  x' = (Xx·wX·x + Yx·wY·y + Ox·w0) / (wX·x + wY·y + w0), y' аналогічно (Xy, Yy, Oy). wX=wY=0 вироджує матрицю;
  майже тотожне перетворення: Xx=Yy=1000, wX=wY=0.001, w0=1.
- Евклідові перетворення діють лише на деталь; афінні/проективні змінюють систему координат - сітка й осі деформуються разом з деталлю.
- Точки, для яких W<=0 (за "камерою"), не малюються.
