# Лабораторна робота №2. Побудова чудових кривих

**Варіант 15 — гіпоциклоїда.** C++17, SFML 2.6, CMake.

## Крива

```
x(t) = (R − r)·cos t + r·cos(kt)
y(t) = (R − r)·sin t − r·sin(kt),      k = (R − r) / r
```

Дефолтні параметри: `R = 5`, `r = 1`.

| Величина | Формула |
|---|---|
| Похідні | `x' = −(R−r)(sin t + sin kt)`, `y' = (R−r)(cos t − cos kt)` |
| Дотична | `y'(X − x₀) − x'(Y − y₀) = 0` |
| Нормаль | `x'(X − x₀) + y'(Y − y₀) = 0` |
| Асимптоти | відсутні (крива обмежена) |
| Довжина дуги | `L = ∫√(x'² + y'²) dt`; при `R/r = n`: `L = 8(R − r)` |
| Площа | формула Гріна; при `R/r = n`: `S = πr²(n − 1)(n − 2)` |
| Радіус кривини | `ρ = (x'² + y'²)^(3/2) / |x'y'' − y'x''|` |
| Точки звороту | `t = 2πmr/R`, їх кількість `n` |
| Точки перегину | відсутні |
