# Лабораторна робота №4 - Побудова гладких криволінійних контурів

Контур дельфіна з Лаб. №3 (кубічні криві Безьє) з гладкістю 1-го порядку у стикових точках.

## Що вміє
- **Вузлова точка** (чорна) - стик, у якому забезпечується гладкість.
- **Реперна точка** (зелена) - контрольна точка характеристичного багатокутника.
- **Точка зламу** (червона) - стик без гладкості.
- Якщо потягнути реперну точку біля вузлової, протилежна реперна точка сусіднього сегмента сама повертається так, щоб точки лежали на одній прямій (формула `B = P + λ(P − A)`, див. `smoothOpposite()` у `Canvas.cpp`).
- **Подвійний клік** по вузловій точці перемикає її: вузлова ↔ точка зламу.
- Прапорець «Гладкість 1-го порядку у вузлових точках» вмикає/вимикає режим для всього контуру.
- Решта функцій із Лаб. №3: характеристичний багатокутник, натяг, анімація, переміщення, поворот, віддзеркалення, скидання.

## Вимоги
Qt 6 (Widgets), CMake ≥ 3.16, компілятор з C++17.


## Файли
- `main.cpp` - вікно та панель керування
- `Canvas.h`, `Canvas.cpp` - контур, гладкість, точки зламу, малювання
- `CMakeLists.txt` - збирання
