# Лабораторна робота №3. Кубічні криві Безьє

**Варіант 15 - контур дельфіна.** C++17, Qt6 Widgets, CMake.

Програма будує контур дельфіна за допомогою кубічних кривих Безьє. Можна переміщувати контрольні точки, змінювати натяг, вмикати гладкі стики, повертати й переміщувати фігуру та запускати анімацію перетворення на трикутник.

## Мета роботи

Навчитися будувати й редагувати контури кубічними кривими Безьє та створювати інтерактивну графіку на C++ із Qt6.

## Завдання

- Побудувати контур дельфіна для варіанта 15.
- Додати відображення та редагування опорних і контрольних точок.
- Реалізувати зміну натягу та гладкі стики.
- Додати переміщення, поворот і віддзеркалення.
- Зробити анімацію переходу від дельфіна до трикутника й назад.
